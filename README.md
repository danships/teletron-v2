# Teletron

Home platform for data sources, displays, actions and AI assistants. A TypeScript hub manages thin nodes over WebSocket. Agents control it through MCP.

## Start

Requirements: Node.js 24 and pnpm 11.

```sh
pnpm setup
cp .env.example .env
pnpm check
```
