# ADR-037: People as a cross-cutting concept, memory keyed by character and person

- Status: Accepted
- Date: 2026-11-08
- Deciders: Dan
- Source: [architecture.md](../architecture.md), section 14

## Context

More than one person lives in the home.

## Decision

People are a cross-cutting concept. Memory is keyed by character and person. Memory is never mixed between people.

## Consequences

- Family members get private memories and pets.
