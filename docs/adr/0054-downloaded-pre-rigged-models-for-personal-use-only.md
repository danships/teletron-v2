# ADR-054: Downloaded pre-rigged models, for personal use only

- Status: Accepted
- Date: 2026-11-09
- Deciders: Dan
- Source: [characters.md](../characters.md), section 3.4

## Context

Making 3D models and rigs is a lot of work. Good free and paid models exist.

## Decision

Prefer downloaded pre-rigged models, for example from Quaternius, Kenney, Sketchfab or VRoid Hub. Use them for personal use only. The skin manifest records the source and license of each model file.

## Consequences

- Skins with these models must not be published or shared outside the home.
